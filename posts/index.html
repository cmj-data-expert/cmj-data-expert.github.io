T-SQL for Comparing Backup and Original Table Structures

테이블 구조 비교 스크립트 (원천 vs 백업) 1. 개요 같은 스키마 안에 있는 원천 테이블과 그 백업 테이블(_BU 접미사) 의 컬럼 구조를 비교하는 SQL Server 스크립트입니다. 어떤 테이블의 어떤 컬럼이 어느 항목에서 다른지를 한 번에 확인할 수 있도록 결과를 임시 테이블에 정리합니다. 대상 DBMS : SQL Server 2017 이상 데이터 변경 : 없음 (조회 전용, 모든 작업은 세션 임시 테이블에서만 수행) 2. 목적 운영에서는 일반적으로 데이터를 주기적으로 백업하고 삭제하는 스케줄러잡이 있습니다.
